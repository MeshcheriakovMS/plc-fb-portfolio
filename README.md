# PLC Functional Blocks Portfolio

Учебно-практический проект по функциональным блокам (IEC 61131-3, ST/SCL)
для CoDeSys 3.5 SP17 Patch 3, TIA Portal V14.

## О проекте
Последовательное освоение FB: от базовых концепций до промышленной
библиотеки и интеграции со SCADA. Итоговый проект — насосная станция
с ротацией, плавным пуском и HMI.

## Стек
- CoDeSys 3.5 SP19
- TIA Portal V14 (SCL)
- Язык: Structured Text / SCL
- Стандарт: IEC 61131-3

## Библиотека блоков
| FB | Назначение | Версия | Документация |
|----|-----------|--------|--------------|
| `FB_Toggle` | Импульсное реле с ручным детектором фронта | 1.0 | [docs/01](docs/01_fb_basics.md) |
| `FB_Motor_Latch` | Пуск/стоп с приоритетом и счётчиком пусков | 1.0 | [docs/01](docs/01_fb_basics.md) |

## Как открыть
1. CoDeSys: `src/codesys/PLC_FB_Portfolio.project`
2. TIA: распаковать `src/tia/Portfolio.zap14`
3. Библиотеки без IDE: `lib/*.library`
